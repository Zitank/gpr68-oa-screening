## Question (one sentence)

Is the available public GPR68 bioactivity data sufficient to train a ligand-based model that generalises across chemical series?

## Hypotheses

- H1 Scaffold-split ROC-AUC CI excludes 0.5. Predicted: no.
- H2 Random split inflates performance relative to scaffold split.
- H3 The learning curve has not plateaued, so a required n can be estimated.

The prediction on H1 is a prediction, not a result. The confidence interval is the result.

## Controls

Scaffold split is the control that matches the question. Random split is the optimistic comparison (H2). Y-scrambling is the null. The applicability domain says which later molecules the fit is even allowed to score. Each endpoint stays in its own analysis. log(activity), pKb, Activity_index, EC50, Activity, Emax and IC50 are not one label.

## Falsifiable form (what result would say no?)

H1's prediction is wrong if the scaffold-split ROC-AUC bootstrap CI excludes 0.5: the public data then look sufficient to support a generalising model, and WP2 is not redirected on data-size grounds. The prediction holds, and the data are not sufficient, if that CI includes 0.5. H2 is rejected if the random-split CI does not sit above the scaffold-split CI. H3 is rejected if the learning curve has plateaued inside the n already in hand, so no larger n is identified.

## So what? If yes: ... / If no: ... / If null: ...

If yes: the scaffold-split CI excludes 0.5. WP2 may continue past this sanity check. The model is still exploratory and is not a claim, and it is not by itself a purchasing list.

If no: the predicted outcome. Redirect WP2 before a long model-building stretch on a set that does not generalise across series. ChEMBL CHEMBL3713916 is 340 activities on 94 molecules from 21 assays and 8 documents, with 67 and 29 molecules from two papers (273 and 60 activity rows) and only 14 pChEMBL values across 10 molecules. That concentration is why "no" is the expected answer.

If null: the learning curve is too noisy to estimate n, or the CI is too wide to call. Do not start a more complex model. Report the curve and stop.

## Cheapest discriminating experiment

One fingerprint-or-descriptor model of the kind the seniors already named (random forest against Morgan fingerprints or basic descriptors), trained only on train and validation. Report scaffold-split ROC-AUC and random-split ROC-AUC, each with a bootstrap CI, a learning curve with confidence bands, a Y-scrambling null, and the fraction of a held-out commercial library that falls inside the applicability domain. No docking and no neural net. The test split stays sealed.

## Risks

Pooling endpoints would manufacture a dataset and make a "yes" meaningless. Ninety-four molecules, most of the rows in two documents, and 13 real inactives against a larger active set can make either split unstable. Ogerin and ZINC32547799 are one matched pair, so scaffold groups may be tiny. A random-split AUC above 0.5 is not evidence for H1. Fitting the prediction "no" into the code, instead of computing the interval, would fake the audit.

## Pilot plan (time box, compute budget, data, what is measured)

Runs on the Intel N100 with scikit-learn. No GPU. Inputs are unpooled rows from ChEMBL CHEMBL3713916 and from PubChem assays that actually contain compounds, including AID 2060853 (52 compounds, 39 active, 13 inactive; absent from ChEMBL). Most other AIDs on GeneID 8111 are siRNA screens with zero compounds and are not ligand rows. Measure the scaffold-split ROC-AUC 95% bootstrap CI, the random-split CI, the Y-scramble null, whether the learning curve has flattened, and an estimated n only if it has not.

## Kill criteria (written BEFORE the pilot)

Written before the model is fit. The bootstrap CI is a 95% interval, fixed here so the stop rule is not chosen after seeing the curve.

1. If the scaffold-split ROC-AUC 95% bootstrap CI includes 0.5, stop WP2 model-building for this sprint. If H3 holds, report the n the curve implies. Do not add a more complex model to chase the random-split number.
2. If the random-split CI lies above the scaffold-split CI, H2 is supported. That inflation is not a reason to continue, and the random-split figure is not the model-quality figure.
3. If the observed scaffold-split ROC-AUC falls inside the central 95% of the Y-scramble scores, the fit is noise. Kill the model and audit the split before any retune.
4. Do not escape rule 1 by pooling endpoints, by dropping to a random split, or by opening the test split.
5. A scaffold-split CI that excludes 0.5 overturns the prediction. It still does not promote a claim.
