## Question (one sentence)

Can an AI-assisted, structure-informed screening workflow identify small-molecule GPR68 modulators that protect cartilage under OA-associated acidic and inflammatory conditions?

## Hypotheses

- H1 A computational workflow can prioritise potential GPR68 modulators above chance, either by structure-based enrichment on the proton-sensing pocket or by a ligand-based model that generalises across chemical series.
- H2 Compounds prioritised that way modulate GPR68 in a receptor-level assay.
- H3 Those modulators protect chondrocytes from OA-associated matrix degradation under acidic and inflammatory conditions.

H1 is the only arm this repository can touch. H2 and H3 are the seniors' experimental questions. This sprint does not answer them.

## Controls

Computational controls live on the children: pocket 2 as a negative site, property-matched decoys, the 13 experimentally measured inactives from PubChem AID 2060853, scaffold split against random split, and a Y-scrambling null. Experimental controls, not run here, are the seniors' condition set (normal, inflammatory, acidic, inflammatory plus acidic) and the markers GPR68, MMP13, ADAMTS5, COL2A1 and ACAN. Bioactivity endpoints are never pooled.

## Falsifiable form (what result would say no?)

The screening workflow is not a reason to buy compounds if Q-002 fails (pocket-1 enrichment does not beat chance, or pocket 1 is indistinguishable from pocket 2) and Q-003 fails (a ligand-based model does not generalise across series). Either child failing kills that arm. Cartilage protection is not tested here, so this repository cannot falsify H3, and a computational pass does not establish H2 or H3.

## So what? If yes: ... / If no: ... / If null: ...

If yes: both children survive their kill criteria, and the workflow is a candidate input to a later 6–10 compound shortlist. That is still exploratory. Nothing in this sprint becomes a claim.

If no: stop using 8Z68 docking scores, or stop the WP2 model, or both, before compounds are purchased. A failed screen does not answer whether GPR68 matters in cartilage.

If null: a confidence interval covers the null, or the result only exists because endpoints were pooled. Do not buy compounds on that result, and do not treat a point estimate above 0.5 as success.

## Cheapest discriminating experiment

The cheapest probe of the programme-as-a-screen is the pair of children, not a cartilage assay. Q-002's enrichment benchmark can kill structure-based prioritisation on this structure. Q-003's scaffold-split learning curve can kill the ligand-based model. The eight-run docking pilot is cheaper still and can show a gross pocket-1 versus pocket-2 difference, but it cannot answer H1.

## Risks

8Z68 chain R is apo (residues 13–297, 2,174 atoms, zero HETATM) and RCSB lists the entry as "To be published", so the structure has no peer-reviewed validation write-up. Ogerin is a positive allosteric modulator and the orthosteric ligand is the proton, so pocket 1 may not be ogerin's site. Calling pocket 1 the proton-sensing orthosteric site and pocket 2 a lipid-facing groove is an exploratory structural reading, not a cited fact. Ogerin and ZINC32547799 are positional isomers, so four compounds cover three scaffolds. ChEMBL CHEMBL3713916 mixes endpoints that must not be pooled. This machine has no discrete GPU, so GNINA CNN scores are not part of the evidence.

## Pilot plan (time box, compute budget, data, what is measured)

This sprint pilots the children, not H2 or H3. Compute is the dev machine in `COMPUTE.md` (Intel N100, 4 cores, no discrete GPU). Data already counted: PDB 8Z68 chain R; ChEMBL CHEMBL3713916 (340 activities, 94 molecules, 21 assays, 8 documents; 14 pChEMBL values across 10 molecules); PubChem AID 2060853 (52 compounds, 39 active, 13 inactive). What is measured is whether Q-002 and Q-003 survive the kill criteria below. Mode stays exploratory.

## Kill criteria (written BEFORE the pilot)

Written before any docking or model run. If Q-002's kill criteria fire, do not choose compounds to buy from 8Z68 docking scores. If Q-003's kill criteria fire, do not spend the WP2 model-building time on this dataset. Both firing retires the computational screen as a purchasing argument. Neither firing, nor both surviving, promotes a result to a claim. Do not pool endpoints to avoid a kill.
